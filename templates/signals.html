📱 开启手机推送（Telegram，5分钟设置）

  1. 在 Telegram 搜索 @BotFather → 发送 /newbot → 取个名字 → 复制 bot token
  2. 搜索 @userinfobot → 点 Start → 复制你的 chat id（一串数字）
  3. 在 Railway → Variables 添加两个变量：
    TELEGRAM_BOT_TOKEN = 你的token
    TELEGRAM_CHAT_ID = 你的chat id
  4. 找到你创建的 bot，点 Start，等 Railway 重新部署即可
